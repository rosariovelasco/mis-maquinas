# Mis Máquinas

App web para anotar las máquinas del gimnasio: peso que usás en cada una, series y repeticiones, foto, observaciones y el historial de pesos con su fecha.

## Cómo usarla

Abrí `index.html` en el navegador (en el celular o en la computadora).

- **Nueva**: agrega una máquina con nombre, peso, series, repeticiones, foto y observaciones.
- Tocá una máquina para ver su detalle, subir o bajar el peso de a 0,5 kg, editar las observaciones, editarla o eliminarla.
- El historial muestra el peso por fecha en barras de colores.

## Dónde se guardan los datos

Abierta como archivo suelto, la app guarda todo en el navegador de ese dispositivo (`localStorage`). Si borrás los datos del navegador, se pierden.

Publicada como artifact de Claude, guarda los datos en tu cuenta y los ves desde cualquier dispositivo.
